# Vestigio Restauraciones

Sitio web en desarrollo de Vestigio Restauraciones, una empresa familiar dedicada a la restauración y conservación de muebles y objetos antiguos. Este proyecto se inició con una base moderna utilizando Vite, React, TypeScript y Tailwind CSS, con el objetivo de construir una presencia digital más escalable, atractiva y fácil de mantener.

🌐 [Ir al sitio](https://www.vestigiorestauraciones.com/)

## 🧩 Estado actual del proyecto
- Proyecto inicial creado con Vite y React.
- Configuración base en TypeScript.
- Estilos implementados con Tailwind CSS.
- Estructura limpia preparada para comenzar a desarrollar las secciones del sitio.

## 🛠️ Tecnologías actuales
- Vite
- React
- TypeScript
- Tailwind CSS
- npm

## 📁 Estructura base
- `src/App.tsx`: componente principal de la aplicación.
- `src/main.tsx`: punto de entrada de React.
- `src/index.css`: estilos globales y configuración de Tailwind.

## ▶️ Cómo empezar
1. Instalar dependencias:
   `npm install`
2. Ejecutar el proyecto:
   `npm run dev`
